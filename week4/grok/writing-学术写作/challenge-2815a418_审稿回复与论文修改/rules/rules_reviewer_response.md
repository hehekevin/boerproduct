# DOMAIN RULES — 审稿回复与论文修改 (kind=reviewer_response)

## Focus
- 答得全: every comment and its sub-requests identified with a clear disposition, not half-answered.
- 改得准: each claimed edit actually lands in the text, locatable in the specified version.
- 证得住: added experiment/data/literature/analysis is verifiable, or why it cannot be done is explained.
- 对得上: response letter, revised manuscript, and version are consistent.

## Rules
1. Decompose comments by id/type/severity/action; split multi-subrequest comments.
2. Per comment: decision (accept/partial/reject)+reason; map 'modified' to a concrete locatable edit.
3. Provide verifiable evidence for additions, or a honest reason if not feasible.
4. Cross-check response letter vs revised ms vs version; keep revision log + diff.

## Self-check
- [ ] all comments/subrequests dispositioned
- [ ] claimed edits locatable in version
- [ ] evidence verifiable or limitation explained
- [ ] letter/ms/version consistent; change log
- [ ] no facts/citations/numbers outside source; gaps flagged
- [ ] editable deliverable + provenance/claim_map + change log; result.json honest
