# DOMAIN RULES — 文献证据驱动写作 (kind=evidence_driven)

## Focus
- 找得到: each substantive claim extracted and linked to a specific passage (not just 'has citation').
- 对得上: reference real, metadata accurate, original text truly supports this claim (not a weaker/stronger one).
- 说得准: strength & uncertainty honest; correlation not causation; single small study not consensus; conflicts not hidden.
- 复得现: evidence map reproducible and auditable.

## Rules
1. Extract claims as decidable units; match supporting source + support scope (multi-ref / multi-claim handled).
2. Pull quotable original spans from full text (not abstract) with section/page/paragraph locator; distinguish study/review/guideline/preprint.
3. Verify reference existence/metadata/numbering vs reference list; detect secondary/circular/decorative citation.
4. Tag evidence strength; express uncertainty; surface conflicting evidence.

## Self-check
- [ ] claims bound to specific passages
- [ ] citations real & support exact claim
- [ ] strength/uncertainty honest; conflicts surfaced
- [ ] evidence map reproducible; editable output
- [ ] no facts/citations/numbers outside source; gaps flagged
- [ ] editable deliverable + provenance/claim_map + change log; result.json honest
