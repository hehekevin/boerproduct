# rules_nanopublication — atomicity, evidence, provenance

## 1. Sources
- Register every ACTUAL file read: {id, path}. Paragraph ids from the material
  (P1..Pn / page:block). Metadata (authors/year/doi) must come from the material
  itself, not from memory or domain labels.

## 2. Assertion atomicity (拆得细)
- One nanopub = one independently truth-evaluable assertion:
  assertion{subject, predicate, object, conditions?}.
- Split compound sentences: "A improves X and reduces Y" → two nanopubs.
- Keep conditions/scope INSIDE the assertion (conditions field): temperature,
  duration, population, "under tested conditions". An assertion without its
 限定条件 is over-broad.
- Subject/object = entities actually named in the material; no commonsense补全.
- predicate from controlled vocabulary: increases decreases causes inhibits
  activates binds measures uses compares outperforms supports contradicts part_of
  associated_with reports contains produces improves. Map原文 verbs to the closest
  controlled predicate; record the original verb in provenance/uncertainty if the
  mapping is interpretive (kind=inferred).

## 3. Minimal sufficient evidence (对得上)
- evidence[{source, paragraph_id, quote}]: quote = the SMALLEST verbatim fragment
  that supports the whole assertion (not the entire paragraph).
- Direct report → kind=reported. Your synthesis across sentences → kind=inferred +
  uncertainty note; never present inference as the authors' assertion.
- If no fragment supports the assertion → status=insufficient_evidence, no assertion
  value, human_confirm:true. If evidence contradicts → source_conflict + both locators.

## 4. Provenance chain (追得回)
provenance{source_id, authors[], year, doi, version?}:
- source_id must be a registered source; authors/year/doi copied from the material.
- Missing metadata → null + note "not_reported"; NEVER invent a DOI/year/author.
- publication_info is generated by the engine (generated_at, derived_from, status).

## 5. Dedup & quality
- Identical (subject, predicate, object) triples → merge into one nanopub with all
  evidence locators (engine flags duplicates).
- Over-broad assertion, wrong relation direction, subject confusion → fix before
  assemble; the engine checks vocabulary, locators, status and duplicates.

## 6. Status vocabulary (mandatory per nanopub)
reported | not_reported | source_conflict | extraction_failed | insufficient_evidence.
Gap statuses: assertion value null/absent, human_confirm:true, reason recorded.
