# 长文档写作检查清单（章节级 / 交付级 / 改稿级）
# 逐项打勾；任一 ✗ 记入 needs_human 或 material_gaps，不得静默跳过。
# 本文件为可复用模板，直接复制到工作目录使用。

## A. 章节规划（写之前）
- [ ] A1 每章有唯一论证任务（回答哪个研究问题 / 支撑哪个结论编号），不是章节名改写
- [ ] A2 每章有字数预算，且全章预算合计 == 材料给出的总字数
- [ ] A3 每章列出所需证据来源（材料编号），材料不足的章标 material_gaps 而非留空
- [ ] A4 章节顺序有论证依赖（方法→结果→讨论），不存在前后倒置
- [ ] A5 章节间无重复论证：同一结论不在两章重复承担

## B. 逐章写作（写的时候）
- [ ] B1 每章先写最小合格版（300-500 字骨架成文），再加深；不一次写完全文
- [ ] B2 每章写完立即回填 draft_all.json 与 result.json 的 deliverable_content
- [ ] B3 每章首次出现术语即用规范写法，并入 registers.jsonl
- [ ] B4 每条论断挂 evidence_map：source_id + locator + ≤30 字逐字摘录
- [ ] B5 正文数值与材料逐字一致；不换算、不外推、不补材料没有的量
- [ ] B6 图表编号按章（图3-1 / 表3-1），正文必须有对应引用句
- [ ] B7 材料不足处写「（材料缺口：…）」或「【待补】」，不删章、不编内容

## C. 跨章一致性（写完之后）
- [ ] C1 同一概念全文只有一种规范写法（变体记入 aliases）
- [ ] C2 符号同符号同义，无同符号多义
- [ ] C3 定义不重复、不少
- [ ] C4 结论编号在登记簿中都能查到，正文引用与登记簿一致
- [ ] C5 前章结论未被后章无声推翻；被推翻时两处联动改并记 conflict

## D. 交付完整性
- [ ] D1 摘要 / 目录 / 图表目录 / 各章 / 参考文献 / 致谢 齐备（completeness_check 三元组全 match）
- [ ] D2 result.json 含 output_contract 全部键 + case_id，缺一个都不行
- [ ] D3 deliverable_content 是论文全文，不是文件指针
- [ ] D4 evidence_map / fact_check / consistency_check / structure_check 均已嵌入
- [ ] D5 thesis.docx 与 thesis.md 均可编辑、可直接打开
- [ ] D6 渲染预览真实存在；无渲染器时 status=no_renderer，不伪造
- [ ] D7 status / uncertainty / needs_human / material_gaps / changelog 如实

## E. 改稿（收到导师/评审意见时）
- [ ] E1 意见逐条拆成可执行修改项，记录：意见原文 → 修改位置 → 落实状态
- [ ] E2 保留作者原句与机器改写句的差异，可回退、可比较
- [ ] E3 修改只动需要动的地方，不顺手重写无关段落
- [ ] E4 每轮改完重跑 C 组机检，确认未引入新冲突

## F. 增益证据（可选，用于证明改进）
- [ ] F1 同一输入跑完整臂与退化臂两遍，指标用同一函数算
- [ ] F2 对照指标至少含：章节完整率 / 跨章编号一致率 / 参考文献覆盖 / 需人工核对条目数 / 步骤数
- [ ] F3 写明机制→指标映射与边界声明（隔离了什么、没隔离什么）
