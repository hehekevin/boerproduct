# 听众适配与叙事规则（talk-plan 配套参考）

目的：把"听众+时长+页数"从口号变成可查表执行的取舍规则，每条都能指回 `adaptation[].because`。

## 1. 听众类型 → 叙事与权重

| audience.type | 首要目标 | 叙事模式 | 页数权重（问题/方法/结果/边界/结论） | 典型质疑 |
|---|---|---|---|---|
| `defense` 答辩 | 认可创新性成立 | 问题驱动：痛点→为何难→我们的解→证据→边界 | 2 / 3 / 3 / 1 / 1 | 创新是否实质、是否只是调参、边界在哪 |
| `group_meeting` 组会 | 理解进度与风险 | 进度叙事：目标回顾→已完成→数据→下一步与风险 | 1 / 3 / 2 / 1 / 1 | 本周做了什么、卡在哪、下一步是否可行 |
| `review` 评审 | 判断结论与证据强度 | 结论先行：结论→三条支撑→方法概述→限制 | 1 / 2 / 3 / 1 / 1 | 证据强度、统计口径、对照是否公平 |
| `public` 公众/科普 | 听懂问题与意义 | 故事线：现象→为什么难→怎么解决→影响 | 3 / 1 / 2 / 0 / 1 | 这跟我有什么关系、数字是否可信 |
| `grant` 基金申请 | 认可必要性与可行性 | 需求驱动：需求→现状不足→方案→预实验→计划 | 2 / 2 / 2 / 1 / 1 | 为何是我们、钱花在哪、风险如何兜底 |
| `lecture` 课堂 | 建立概念结构 | 概念递进：定义→机制→例证→易错点→小结 | 2 / 3 / 2 / 1 / 1 | 与前序概念的关系 |

## 2. 时长 → 页数与密度（机械算式）

- 页数上限 ≈ `duration_min ÷ 1.5`（15min→10 页、10min→6-7 页、20min→13 页、5min→3-4 页；含封面与结论）。
- 单页时长建议 `0.8–2.0 min`：标题/过渡页 0.5，方法页 2.0-2.5，结果页 1.5-2.0，限制页 1.5。
- 备用问答页 `minutes: 0`，不计入正片页数与总时长（校验 C4_backup_zero）。
- 硬性约束：`Σ section.minutes = Σ 正片 slide.minutes = constraints.duration_min`，误差 ≤0.05 min。

## 3. 内容取舍优先级（超预算时按序砍）

1. 相关工作/文献综述 → 压成 1 句，或直接并入问题页
2. 实现细节（超参、工程 trick）→ 移入备用页
3. 第二、第三结果 → 合并为「结果族」一页，只留最强证据
4. 方法的多层次细节 → 保留"听众能复述机制"的最小集（每组件一条要点）
5. **不砍**：限制页、结论页、唯一强证据结果页

## 4. 证据强度 → 措辞对照（避免夸大）

| 强度 | 判定 | 可用措辞 | 禁用措辞 |
|---|---|---|---|
| 强 | 多数据集/多批次 + 消融支撑 | 支持、显示、在该设置下提升到 | 普遍适用、彻底解决 |
| 中 | 单实验、单批次，或作者自己承认限制 | 初步表明、在该批次上观察到 | 证明、显著优于 |
| 弱 | 推论、相关工作佐证、无直接数据 | 推测、可能、有待验证 | 证明、首次、必然 |

## 5. 问答四类与备用页映射

| 类别 | 追问原型 | 备用页该放什么 |
|---|---|---|
| `mechanism` 机制 | 为什么有效？为什么不是别的解释？ | 机制示意 + 消融数据（同一 quote 口径） |
| `data` 数据 | 样本量？口径？清洗？统计检验？ | 样本表 + 判定标准 + 批次一致性 |
| `control` 对照 | 基线公平吗？同条件吗？ | 对照设置表（同条件逐项列出） |
| `limitation` 局限 | 能迁移吗？边界在哪？ | 作者原话的限制 + 未验证范围 |

规则：`qa[].answer` 的数字必须与 `pointer_slide` 页面数字来自**同一 quote**（口径一致），否则现场会自相矛盾。
