# 解析执行细则（parsing-rules）

供 SKILL.md 第 3、4 步引用的确定性规则。逐条执行，规则解决不了的留给 `unknown` + uncertainty，不猜。

## 1. 页眉页脚剥离

- 取第 2、3 页（非首页）的文本行，首尾各取 1-2 行。
- 多页重复出现（页码、期刊名、会议名、DOI 行）→ 标记 `header_footer`，从正文段落剔除，但在 result.json 的 `header_footer` 字段（若契约有）保留记录。
- 首页的论文标题/作者行不属于页眉，保留。

## 2. 双栏阅读顺序

- 判定：取一页正文行，若行的 x 起点明显聚成两簇（如左半 < 页宽 40%，右半 > 页宽 55%），判为双栏。
- 双栏页输出顺序：先左栏整栏（按 y 从上到下），再右栏整栏。
- 通栏元素（大标题、宽题注、页首摘要）按 y 坐标插入到正确位置。
- 三栏同理，按簇从左到右逐栏输出。

## 3. 跨页段落合并

合并条件（同时满足才合并）：

1. 页 N 最后一个文本块以句号以外的标点或无标点结束（句子被截断）；
2. 页 N+1 首个文本块以小写字母、连字符词或接续词开头；
3. 两块都不属于标题、列表项、题注、参考文献条目。

合并动作：连字符断词去连字符拼接，其余逐字拼接；在 result.json `changes` 记 `{step: "merge", merged_pages: [N, N+1], order: <段落序号>}`。

## 4. 图表题注-正文引用配对

- 题注识别：以 `Figure N` / `Fig. N` / `Table N` / `图 N` / `表 N` 开头的独立文本块。
- 引用识别：正文中出现的同编号引用（如 `as shown in Figure 3`），记首次出现页码与片段。
- 配对：按编号一致配对，输出 `figure_id`、`caption`（逐字）、`page`、`cited_at`。
- 找不到单侧：保留已有侧，`pairing: "unmatched"`，登记 uncertainty（原因：caption not found / citation not found）。

## 5. 章节层级

- 优先用编号判定：`1.` / `1.1` / `2.3.1` / `I.` / `IV.A` 等前缀映射层级深度。
- 无编号文档用字号/加粗线索推断，节点标 `level_source: "inferred"`；有编号标 `"numbered"`。

## 6. 参考文献

- 起点定位：`References` / `Bibliography` 标题所在页。
- 切分：以 `[N]` / `N.` 行首编号为界逐条切分；无编号时以缩进/悬挂缩进变化为界，标 `split_confidence: "low"`。
- 跨页条目按规则 3 合并。逐字保留，不改正文格式。

## 7. 公式与特殊字符

- 按提取原文保留字符序列（含 Greek 字母、上下标符号），标注 `page` 与行号。
- 有编号的（`(1)`, `(2)`）记录公式编号。
- 提取乱码或丢失时值填 `"unknown"`，uncertainty 登记，不重写公式。

## 8. 证据定位约定

- 每个区块输出必带 `page`（物理页序，从 1 开始）。
- 外部 MD 副本中每区块标题格式：`## [p.N] 区块类型 #序号`，保证人工可抽查回原文。
