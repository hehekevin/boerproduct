# 数据字典（SYNTHETIC 示例）

p1: 主键为 sample_id + timestamp（样品编号 + 采样时间）。同一样品同一时间只应有一条记录；重复导出保留首次。

p2: conc 字段哨兵值约定：-999 为存储故障哨兵值（不是测量值）；空字符串为录入缺失；ND 为未检测；<LOD 为低于检出限。真值 0 表示"检测为 0"，是有效测量，不得当作缺失。缺失/无效源值一律标记保留，不得填补。

p3: 浓度目标单位为 ug/L。换算关系：1 mg/L = 1000 ug/L；1 ug/mL = 1000 ug/L。unit 列记录原始单位，换算须可逆并保留原值。

p4: 异常值判定：结合物理上下限与分布诊断（IQR，k=1.5）。异常值可能是真实高值或加样失误，默认标记并转人工确认，不静默删除。
