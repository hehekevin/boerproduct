# Blue-light filtering lenses shorten sleep onset in adult insomniacs (2019)

Source-id: S2
Year: 2019
DOI: 10.0000/example.s2
Status: SYNTHETIC EXAMPLE DOCUMENT (fictional; not a real publication).

[P1] Wearing blue-light filtering lenses for 3 hours before bed shortened sleep onset latency by 18 minutes in 60 adult insomniacs (randomized, sham-controlled).

[P2] Self-reported sleep quality improved, but actigraphy total sleep time did not differ significantly.
