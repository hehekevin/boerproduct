# Task (SYNTHETIC EXAMPLE)

Produce compilable LaTeX source (main.tex + references.bib) from the provided content
(`content.md`). Valid structure (balanced braces, matched \begin/\end), required
sections, \cite keys present in the bib, \ref labels defined. The runtime has a
latex-compiler; locally only structure is validated (no local TeX). Be honest that
compile is not run locally. Interface demonstration only.
