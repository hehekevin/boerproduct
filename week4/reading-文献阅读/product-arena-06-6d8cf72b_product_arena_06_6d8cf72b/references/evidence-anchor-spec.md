# 证据锚点格式规范

## 目的

保证每条关键笔记可以按锚点回到原文唯一位置，且锚点粒度与结论的可核验性匹配。禁止"见原文""见第2节"这类笼统出处。

## 锚点组成

锚点由四类坐标组成，按需组合，至少含两类：

| 坐标 | 格式 | 示例 | 说明 |
|---|---|---|---|
| 页码 | `p.数字` | `p.3` | PDF 物理页码，从 1 起 |
| 章节 | `§章节号` | `§3.2` | 章节编号加章节名，如 `§3.2 Loss Design` |
| 段落 | `¶数字` | `¶2` | 该章节内第几段；表格前后段落单独计 |
| 图表公式 | `Fig.数字` / `Table数字` / `Eq.数字` | `Table 1` | 用论文自身编号，不改写 |

组合写法：`p.5 §3.2 ¶2 Table 1`，表示第 5 页第 3.2 节第 2 段及其引用的表 1。

## 粒度与结论类型匹配

| 结论类型 | 最低锚点要求 |
|---|---|
| 数字类结论（指标、样本量） | 页码 + 表号或所在段落 |
| 方法条件（超参数、设置） | 页码 + 章节 + 段落 |
| 研究问题、结论 | 页码 + 章节 + 段落 |
| 局限 | 页码 + 章节 + 段落 |
| 评价性条目（阅读者判断） | 不要求锚点，但须放在评价栏 |

## 规则

1. 页码以 PDF 物理页为准，与论文印刷页码不同时以物理页为准，可加注 `(印刷页码 12)`。
2. 段落计数从章节标题后第一段为 ¶1。
3. 表格内具体单元格可用 `Table 2, row 3` 进一步定位。
4. 双栏 PDF 以重排后的顺序计数段落，存疑时在锚点后加 `[?]` 并列入无法判断清单。
5. 非中文论文摘录保留原文位置，翻译件需加注"译"并保留原锚点。
6. 每条锚点写入笔记后应可独立复核：第三者只凭锚点能在 30 秒内找到对应原文位置。

## result.json 中的对应字段

anchors 数组中每项含 claim、page、section、paragraph、figure_table 五个键，与本规范坐标一一对应；无图表定位时 figure_table 填 null，不省略键。
