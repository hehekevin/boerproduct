# resources/claim-map-template.md

论断-来源映射表格式（可选参考；Agent 可直接在 /app/work/claim_map.md 按此格式落盘）。

## 论断条目

每行一条，竖线分隔四列：

```
C<编号> | <论断内容：数字/术语/他人结论/图表指涉> | <来源编号+定位：如 S1 §2 段3> | <直接引用 或 作者判断>
```

示例：

```
C1 | 基线方法在数据集 Y 上 F1 为 82.4% | S1 §4 表2 | 直接引用
C2 | 先前工作未覆盖低资源场景 | S2 §5 段1 + S3 §6 段2 | 直接引用（空白推导依据）
C3 | 该问题在实际部署中代价敏感 | 无来源 | 作者判断（行文中须标注）
```

## 贡献-证据条目

```
CT<编号> | <贡献表述> | <证据位置：方法章节号/表号/图号> | <对齐 或 降级>
```

示例：

```
CT1 | 提出模块 M，在 X 任务上提升 3.2% | §3 方法、§5 表3 | 对齐
CT2 | 方法适用于所有模态 | 未找到证据 | 降级为"在文本模态上验证"
```

## 使用规则

1. 映射表中没有的事实，写作时要么不写，要么标注为作者判断。
2. 研究空白只能引用标记为"空白推导依据"的条目推出。
3. 引用元数据无法确认时用 `[CITE?: 待查]` 占位，不编造。
