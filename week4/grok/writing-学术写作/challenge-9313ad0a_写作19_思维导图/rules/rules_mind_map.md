# DOMAIN RULES — 思维导图 (kind=mind_map)

## Focus
- 抓得准: identify core concepts/question/method/evidence/conclusion/task, not decorative words.
- 理得清: sensible root/hierarchy/sibling granularity; no cross-classification/duplication/buried key info.
- 连得对: causal/dependency/contrast/temporal/citation/support/conflict relations only if sourced.
- 证据可追溯: key nodes/relations attach evidence; layout readable & editable.

## Rules
1. Extract nodes with source+locator; attach evidence tags; avoid decorative nodes.
2. Build root/levels with consistent sibling granularity; no overlap/dup.
3. Add typed cross-relations only when the material supports them; legend matches.
4. Emit layered editable SVG + PNG/PDF; keep node/relation provenance.
