# 符号表模板

用途：统一管理全篇符号，保证一符一义、首次出现即定义、正文与公式一致。Phase 1 抽取时初建，Phase 3 写作与 Phase 4 自检时维护。

## 符号表

| 符号 | 含义 | 单位 | 首次定义位置 | 出现位置 | 一致性 |
|---|---|---|---|---|---|
| N | 训练样本数 | 无 | 2.X 第 1 段 | 2.X、2.Z | 一致 |
| lr | 初始学习率 | 无 | 2.Z 第 1 段 | 2.Z | 一致 |
| alpha | 学习率调度中的衰减系数 | 无 | 2.Z 第 2 段 | 2.Z 公式(1) | 冲突：公式中作下标 |

字段规则：

1. 符号：按材料原样记录（含大小写、下标、粗斜体约定）。
2. 含义：用一句话说明，与正文定义句一致。
3. 单位：无量纲写 无。
4. 首次定义位置：正文中第一次给出定义的章节与段落；若正文尚未定义，写 未定义，Phase 4 必须补定义或改写。
5. 一致性列取值：一致、冲突、未定义。

## 一致性规则

1. 一符一义：同一符号不得表示两个含义；发现复用时改用新符号并在映射表记变更。
2. 一义一符：同一含义全文用同一符号，禁止同义混用（如 accuracy 与 acc 混用）。
3. 首次定义：符号首次出现处必须紧跟定义句（如 We denote X as Y）。
4. 公式与正文一致：公式中的符号、下标与符号表逐字核对。
5. 指标名视同符号：评估指标（accuracy、F1 等）在指标小节统一定义，后文引用同名。
6. 与材料一致：符号写法优先与材料中的代码或公式一致；材料内部写法冲突时，选多数派并在冲突清单记录。
