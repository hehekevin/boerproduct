# DOMAIN RULES — 学位论文与长文档写作 (kind=thesis_longdoc)

## Focus
- 立得住: chapter plan matches outline, argument chain, word allocation (not material piled into prose).
- 连得上: cross-chapter terms/definitions/symbols/numbering/figure refs/conclusions consistent; find affected paragraphs on edit.
- 改得动: local edits touch only what's needed, preserve author intent; author sees what/why changed.
- 查得清: every claim/citation traceable.

## Rules
1. Plan chapters with per-section question + required evidence + word budget; avoid overlap/gaps.
2. Maintain glossary/symbol/definition/conclusion registries; detect conflicting writes & duplicate definitions; on edit, locate affected cross-refs.
3. Apply localized traceable revisions; preserve original phrasing elsewhere.
4. Bind claims/citations; flag doubtful refs; run consistency checks.

## Self-check
- [ ] chapter plan matches outline/argument/budget
- [ ] cross-chapter consistency; affected paras found
- [ ] local edits preserve intent; traceable
- [ ] claims/citations traceable; editable output
- [ ] no facts/citations/numbers outside source; gaps flagged
- [ ] editable deliverable + provenance/claim_map + change log; result.json honest
