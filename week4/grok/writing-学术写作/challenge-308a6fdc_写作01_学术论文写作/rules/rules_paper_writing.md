# DOMAIN RULES — 学术论文写作 (kind=paper_writing)

## Focus
- 写得实: numbers/units/sample size/captions/conclusions come from given material & real literature, not model completion.
- 引得对: each citation truly supports its claim; authors/year/journal/DOI accurate & checkable.
- 全得起来: discipline template sections/figures/refs/declarations complete; missing items explicitly flagged.
- 改得动: keep heading hierarchy, caption numbering, citation format; editable in Word/Markdown with per-item review.

## Rules
1. Build a material index; every fact/number/caption cites a source locator.
2. Bind each claim to evidence + citation_ids; verify citation metadata/DOI against the provided reference list; flag unverifiable refs.
3. Assemble required sections (abstract/intro/methods/results/discussion/conclusion/refs/data-availability); flag missing.
4. Run number-consistency + terminology checks before delivery; keep revisions traceable.

## Self-check
- [ ] facts/numbers/units from source
- [ ] citations support claims & metadata accurate
- [ ] required sections present (missing flagged)
- [ ] editable md+docx; claim_map + change log complete
- [ ] no facts/citations/numbers outside source; gaps flagged
- [ ] editable deliverable + provenance/claim_map + change log; result.json honest
