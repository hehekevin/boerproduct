# 结构化笔记模板

使用说明：复制本模板填写。`锚点` 处必须填入证据定位（格式见 evidence-anchor-spec.md），禁止留空或写"见原文"这类笼统出处。事实栏与评价栏必须分开填写。

```markdown
# 论文结构化笔记：{论文标题}

## 0 元数据

- case_id：{案例标识，来自 case.json}
- 论文标题（原文）：{原文标题}
- 论文标题（中文译名）：{译名或"无"}
- 作者与机构：{从首页抄录，附锚点}
- 发表信息：{期刊/会议/年份/版本，附锚点}
- 论文总页数：{页数}
- 笔记生成状态：{成功 | 部分完成 | 无法判断 | 失败}
- 笔记作者声明：本笔记事实栏内容均来自论文原文，评价栏为阅读者判断。

## 1 研究问题

| 论文事实 | 锚点 | 阅读者评价 |
|---|---|---|
| {论文要解决的核心问题} | {锚点} | {问题重要性、动机是否成立等判断，可为空} |
| {论文声称的贡献点，逐条} | {锚点} | {贡献是否新颖的判断，可为空} |

## 2 数据

| 论文事实 | 锚点 | 阅读者评价 |
|---|---|---|
| 数据集名称：{名称} | {锚点} | {规模是否够大、是否公开等判断} |
| 数据规模：{样本量/条数，逐字抄录} | {锚点} | |
| 数据来源与划分：{训练/验证/测试划分} | {锚点} | 若未报告，写"未报告" |
| 预处理方式：{步骤} | {锚点} | |

## 3 方法与前提条件

| 论文事实 | 锚点 | 阅读者评价 |
|---|---|---|
| 方法名称与一句话概括：{内容} | {锚点} | {方法是否合理的判断} |
| 关键设置/超参数：{逐字抄录} | {锚点} | |
| 前提假设：{方法或结论成立的前提} | {锚点} | 若未报告，写"未报告" |
| 基线方法：{对比对象} | {锚点} | |

## 4 主要发现（结果）

| {发现2} | {锚点} | |

|---|---|---|---|
| {指标名} | {值+锚点} | {值+锚点} | [数字已核对] / [数字冲突] / [数字无表格来源] |

## 5 局限与限制条件

| 论文事实 | 锚点 | 阅读者评价 |

| 类型 | 内容 | 锚点 |
|---|---|---|
| 可引用结论 | {可直接引用的事实性结论} | {锚点} |

- 未报告：{字段名}，论文未提及，位置范围 {章节/页码}。
- 无法判断：{内容}，原因：{材料不足以确认}。
```
