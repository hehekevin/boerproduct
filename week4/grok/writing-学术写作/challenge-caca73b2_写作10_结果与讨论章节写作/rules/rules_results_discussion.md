# DOMAIN RULES — 结果与讨论章节写作 (kind=results_discussion)

## Focus
- 读得准: figure values/units/error-bar meaning/scale/stats read correctly into text, not guessed.
- 分得清: Results states observations only; Discussion carries interpretation/lit-comparison/limits; no role swap.
- 说得住: trend/difference/causal wording backed by data/test; tone matches evidence strength.
- 核得了: every number traces to a figure/table/stat output.

## Rules
1. Read data table/figure/caption/stat output; handle unit conversion, sig figs, error-bar meaning, multi-panel/supplement numbering.
2. Results organized by figure/question, observations only; Discussion interprets + compares literature + limits.
3. Match trend/direction/magnitude/significance wording to evidence; no causation from correlation.
4. Bind every number to source; run number-consistency check; flag gaps.

## Self-check
- [ ] numbers/units/error bars read correctly
- [ ] results vs discussion separated
- [ ] strength matches evidence; no overclaim
- [ ] every number traceable; editable output
- [ ] no facts/citations/numbers outside source; gaps flagged
- [ ] editable deliverable + provenance/claim_map + change log; result.json honest
