# 多篇笔记合并对比模板

使用说明：对同一领域多篇论文各自生成结构化笔记后，用本模板合并为对比表。字段为行，论文为列。合并时只搬运笔记中带锚点的事实栏内容，评价栏单独一行并标注来源笔记。

```markdown
# 多篇论文对比笔记

## 对比范围

- 参与论文：{笔记文件名列表，各含 case_id}
- 对比维度说明：字段为行，论文为列。

## 对比表

| 字段 | 论文A：{短标题} | 论文B：{短标题} | 论文C：{短标题} |
|---|---|---|---|
| 研究问题 | {内容+锚点} | {内容+锚点} | {内容+锚点} |
| 数据 | {名称/规模+锚点} | | |
| 方法 | {方法名+锚点} | | |
| 关键设置 | {超参数+锚点} | | |
| 主要发现 | {数字逐字+锚点} | | |
| 局限 | {+锚点} | | |
| 结论 | {+锚点} | | |
| 阅读者评价 | {来自笔记A评价栏，标注来源} | | |

## 横向观察（评价性内容）

- {方法差异、数据规模差异、结论冲突等观察；属评价栏，不冒充论文事实}
- 数字口径不一致处：{说明各论文指标定义差异，避免直接比较不可比数字}

## 缺口提示

- 论文X未报告：{字段}，对比该行时注意。
```

## 合并规则

1. 每个单元格必须沿用原笔记的锚点，不重新定位、不省略。
2. 原笔记标"未报告"的字段照抄"未报告"，不猜测补齐。
3. 指标定义不同的数字不放进同一行直接比较，放入"横向观察"说明口径。
4. 合并结果仍须通过 self-check-list.md 第三、五、六组检查。
