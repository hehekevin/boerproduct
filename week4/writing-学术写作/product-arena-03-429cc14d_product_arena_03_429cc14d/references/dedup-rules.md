# 去重合并判据与误合并防护

## 一、合并主判据（按优先级执行）

| 级别 | 判据 | 动作 |
|---|---|---|
| J1 | DOI 完全相同（规范化后，大小写不敏感） | 自动合并 |
| J2 | arXiv ID 相同 | 自动合并，保留版本信息 |
| J3 | ISBN 完全相同（图书） | 自动合并 |
| J4 | 第一作者姓+年份+题名规范化后完全一致 | 自动合并，risk=low |
| J5 | 题名规范化后高相似（去标点/大小写/空白后编辑距离很小）且年份相同 | 待确认，不自动合并 |
| J6 | 预印本与正式版：题名一致或近似，且预印本记录中含正式版 DOI/期刊信息 | 自动合并到正式版，risk=low，写明依据 |
| J7 | 同一文献中英题名并存（双语言发表或数据库双语字段） | 仅当 DOI 或卷期页一致时合并，否则待确认 |

题名规范化函数：转小写、去标点与空白、去"研究/on the/a/an/the"等填充词不做（避免过度规范化），仅做字符级规范化。

## 二、禁止合并的情形（误合并防护）

1. 同名作者的不同文献：作者匹配但题名不相似，不合并。
2. 同题名不同年份：多为综述系列或再版，不合并，列待确认。
3. 会议版与期刊扩展版：题名常不同（扩展版加新词），默认两条并存，除非材料明确说明同一工作，列待确认并注明"期刊扩展版"关系。
4. 中文拼音重名作者（如 Wang Wei）：年份与题名任一不同即不合并。
5. 期刊同名栏目或系列论文（Part I/II）：副标题不同即不合并。

## 三、合并执行规则

1. 字段择优顺序：正式版 > 完整字段多 > 来源库权威性（出版社/期刊官方 > 数据库导出 > 手工录入）。逐字段择优，不是整条二选一。
2. 合并记录四要素必填：保留条目键、被并条目键（可多个）、判据编号（J1 到 J7）、风险等级（low/medium/conflict）。
3. 被并条目的原始格式串全文留档于 dedup_records.evidence，供回溯。
4. 合并后旧键映射表更新：正文所有引用点的条目键同步替换。
5. risk=conflict 或待确认的一律不合并，进入 manual_review_list，附上两边的差异字段对比。

## 四、去重后的对账

- 合并组数、被并条目数、待确认对数三个数字写入 result.json 的 dedup_records 汇总。
- 对账公式：去重后条目数 = 原始条目数 - 自动合并被并数。不等即为漏记，必须修正后再进入阶段 3。
